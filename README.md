# eRegistrar

CS425 Software Engineering course project.

Ziad El Fatih, 618971

eRegistrar is a course scheduling and registration system for a university
department. The registrar builds the term schedule and assigns faculty,
faculty maintain their availability, and students register for sections
online.

## Contents

| Folder | Contents |
