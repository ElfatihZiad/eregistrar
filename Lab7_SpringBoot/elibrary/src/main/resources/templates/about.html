About this application

Built with Spring Boot 2.7 and Spring MVC on Java 11, with Thymeleaf for server-side rendering and Spring Boot DevTools for automatic restart and LiveReload during development.

  • Build: Apache Maven
  • Controller: edu.mum.cs.cs425.elibrary.controller.HomeController
  • Templates: src/main/resources/templates
  • Static assets: src/main/resources/static
